# competitor-teardown

Скилл для [Claude Code](https://claude.com/claude-code): **разбор лучших игроков ниши**.
Находит, кто в нише реально «стреляет», а не просто большой, разбирает их залетевшие ролики
по блокам, смотрит, что они раздают как лид-магнит и что продают следом, и предлагает
клиенту свои лид-магниты и продуктовую линейку, включая то, чего в нише никто не делает.

## Когда применять

- Deep Research дошёл до темы игроков и конкурентов: пора разобрать, кто из них сильный и почему.
- «Посмотри, кто в нише лучший», «разбери их рилсы», «из чего собран этот ролик».
- Нужно понять, какие лид-магниты и продукты в нише уже работают и где пусто.

## Вызов

Скилл подхватывается сам по словам «разбор конкурентов», «кто в нише лучший», «разбери их рилсы».
Или напрямую:

```
/competitor-teardown
```

## Что делает

| Шаг | Что происходит |
| --- | --- |
| 1. Полсотни кандидатов → десять лучших | Аккаунты находит система, а не клиент: поиск по словам ниши и граф похожих. Отбор по формуле из вирусности, комментариев и свежести, подписчики не считаются |
| 2. Десять критериев | По последним 30 роликам: медиана просмотров, вирусность, стабильность попаданий, комментарии, сохранения, частота, динамика, продающий слой |
| 3. Разбор роликов по блокам | Хук, контекст, боль, поворот, механизм, доказательство, оффер, CTA. Какая сборка выигрывает именно в этой нише |
| 4. Лид-магниты и продукты | Что в шапке, что раздают даром, как забирают контакт, что продают следом и по какой цене |
| 5. Что предложить клиенту | Три лид-магнита, линейка продуктов с ценами и то, чего в нише не делает никто |

На выходе файл `01-ресёрч/04-конкуренты.md`: таблица десяти аккаунтов, группы «охват / вовлечение / продажи»,
разбор лучших роликов, дословные хуки победителей и предложение для клиента.
